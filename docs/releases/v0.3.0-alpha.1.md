# 智研助手 v0.3.0-alpha.1

这是面向生物医学及相关专业大学老师的 Windows Alpha 测试版。这一版把软件重新组织为“说一句话，AI 完成；说一句话，AI 修改”的工作方式，并按课程和课题整理成果。

## 本次升级

- **一句话完成**：教案、课件、教材章节、文献报告、证据表、数据分析报告和随堂题，说一句要求即可完成。AI 先读出要点（可以直接改），再自动完成；也可以选择“逐步确认”，每一步先看再继续。
- **说一句就改**：成果可以按整份、某一部分或选中的文字修改，改动会高亮显示，可以保留或撤销，每次修改都保存版本。
- **我的课程、我的课题**：把课程章节、授课对象、术语表，或课题的科学问题、关键术语写一次，之后在项目里做的成果都按它来写，并自动归入项目文件夹。
- **记住习惯**：说“以后都……”或多次做同样的修改时，软件会提议记住；在“设置 → 我的偏好”中可以查看和删除。
- **一句话做整套**：一句话里提到多个成果（如“第八章的教案、课件和 10 道选择题”）时，会在任务中心排队依次完成；做完一个成果后会推荐下一步。
- **交付前自查**：右栏显示“AI 已自查：N 处建议”，包括到 PubMed 核对引用的 PMID/DOI、统一术语写法、检查课件每页文字量、教案时长和国自然申请书结构，可以逐条采纳或忽略。
- **示例项目**：首次设置完成后可以选择“看看示例”，装入一门示例课程和一个示例课题（内容为虚构，可随意删除）。
- **界面更清楚**：侧栏改为 首页 / 我的课程 / 我的课题 / 文件库；写作入口合并为“文稿”；AI 助手可在任何页面打开；统一字号、颜色和页头，去掉技术用语；支持键盘操作、Esc 关闭弹窗，深色模式逐页检查；Windows 上可按 Win + H 语音输入。

## 安装与使用

1. 下载 `ZhiYan-Assistant-0.3.0-alpha.1-win-x64.exe`。
2. 按安装向导完成安装并打开智研助手。已安装旧版本的，直接安装即可覆盖升级，原有设置和文稿会保留。
3. 选择 DeepSeek、Kimi、通义千问或智谱 GLM，填写该平台的 API Key。
4. 选择“看看示例”先了解成果的样子，或直接说一句要做什么。
